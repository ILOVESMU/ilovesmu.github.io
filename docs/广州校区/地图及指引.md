# 地图及指引

## 先看简化地图

为方便新生快速找到重要建筑，在过去地图的基础上重新做了一份简化版地图。如果知道目的地，也可以直接用各类电子导航地图；南方医院院内地图可关注南方医院公众号，有院内导航。

教学馆、高层公寓、食堂一字排开，图书馆、体育馆和操场也在旁边，日常上课和生活比较集中。

## 楼层怎么对应

学校这边地形有一点复杂，主要是楼层编排：

- **高层一楼 = 教学馆一楼 = 图书馆一楼 = 数字栋一楼 = 学二食堂**
- **人体科学馆 = 操场 = 体育馆 = 学一食堂**

第一次找教室时，先确认自己说的是“几楼”，不要只看建筑名。

## 其他区域

还有很多平时不太会涉及的区域：

- **护理楼**：里面有一些医工仪器，影像专业的 X 线试卷也会存放在这里，护理学的课也在这里上。
- **生科楼**：研究生和一些老师的地盘，平时外卖也可以直接送到这里。
- **财务结算中心、校内中国银行**等也在校园里。

剩下的区域可以等自己实地探索，或者直接在电子地图里搜建筑名。
