怎么读才够快

  1. 先看「一句话抓住」，再看核心内容。一句话抓住是本课的机制或矛盾，读懂它，后面的方法才有落点。
  2. 只细读标了「掌握」的小节。标「熟悉」的扫读，能说出方法和用途即可；标「了解」的只看结论，不要停下来推公式。
  3. 「易混点」必须逐条背下来。这一节是判断题和单选题的主要来源，每条都是一组对立概念。
  4. 「英文考点」每次学完过一遍。考试有英文题、占比不超过 30%，课堂上强调的英文单词与短语要能写出来。
  5. 「可能这样问」只看问题、先自己想答案。想得出来就过，想不出来再回正文那一段，不要重读整课。
  6. 读不懂的先跳过。卡住超过两分钟就往下走，做题时错回来查，比硬啃快。

时间不够时的取舍顺序

  1. 先保「易混点」与「英文考点」——这两部分最短、命中率最高。
  2. 再保每课的「一句话抓住」与「可能这样问」。
  3. 核心内容只读「掌握」小节，其余整段跳过。
  4. 题库只做标记为「掌握」的客观题，问答题读题干与答案要点，不默写。

三个实验课时（exp-01 至 exp-03）操作参数多、占比低，时间紧时只读「原理」「计算」「注意事项」三节。

各分组的分工：基础方法是基础方法——样品怎么采、怎么处理，后面每一章都建立在这三步上。；营养成分——第四章的七个单元，按成分逐个讲方法。；专题检验——安全相关的检验：添加剂、农残、兽药、毒素、污染物、真实性。；实验训练——三个实验，分别练快速筛查、分光光度定量与目视比色。
