# XIN公益

Hi 新同学～

你是否想过，大学里有一段时光，既能为远方孩子点亮微光，又能让自己收获成长？
XIN公益，就是这样一个地方——

🌱 我们从2007年5月起步，2009年在南方医科大学正式注册，是以贵州支教为起点的综合性公益社团。
🏆 校级十佳社团，连续多年获评“十佳”，综测加分分量十足！
❤️ 现由 九秋、心坡、都岭、猩猩、灵青 五支支教队 + 义工服务队 组成，秉承 “助人与自助” 的理念，让梦想从XIN开始！

## 加入我们能得到什么？

- ✅ 参与支教/义工 → 志愿时
- ✅ 校级社团+十佳社团 → 综测
- ✅ 一群温暖有趣的伙伴，一段刻进青春的故事

**📌 报名方式：加入q群，扫码填写报名表！**

公益是一场双向奔赴。
XIN公益，等你来，让我们的故事从一份报名表开始！
