# 生命健康

## 校医室与转诊

携带学生证到校医室（数字栋 16 栋一楼）挂号窗口挂号，到诊室就诊，然后缴费、取药。

如果校医室无法解决，会给你盖转诊章办理转诊。之后在“南方医科大学南方医院”微信公众号预约挂号。到预约时间后，带上转诊证明、学生证去医院科室分诊台报到候诊。

就诊结束后去**人工窗口**缴费，出示转诊证明、学生证原件或电子版照片。注意不要在手机上或自助机自行缴费，否则可能无法享受医保待遇。缴费后再去药房取药。

就医、取药的报到候诊可以在自助机完成，等待屏幕叫号；只有缴费建议去人工窗口。

## 医保

如果不用医保报销，就不需要校医室转诊，可以直接去医院就医，随便找自助机缴费。

不是学校医保也可以在南方医院使用：

- **广州医保**：需要把南方医院添加到定点医院；
- **非广州医保**（比如佛山医保）：先在粤省事办理异地就医备案，学生可以按“异地长期居住人员”办理，然后在医保小程序里定点到南方医院，通过后才能使用。

## 预约与院内导航

可以关注校本部门诊部公众号预约挂号。挂号成功后，微信服务号会发预约成功通知，里面可以看到就诊地点；也可以使用南方医院院内导航小程序。

门诊楼不算很大，跟着院内导航一般很容易找到。AED 位置见[地图及指引](地图及指引.md)，具体以最新地图为准。
