第四章 青春期生长发育

青春期概念、生长突增、性发育和性心理。

顺序学习纯刷题文字游戏
这一章怎么记记不住时点开

先把 adolescence、puberty、puberty timing 分清：一个讲阶段，一个讲过程，一个讲时间。

  • 三个词各问各的adolescence 是从童年向成年过渡的年龄段；puberty 是青春期早期生殖系统发育成熟的生物学过程；puberty timing 是这些事件什么时候开始、按什么顺序发生。英文题基本就在这三者之间绕。相关章节：儿童少年身体发育
  • 生长突增从脚和腿先开始顺序大致是足长、下肢长、手长、上肢长，所以先出现“腿变长”的体态，坐高指数先降；青春中后期躯干追上来，坐高指数再回升。相关章节：儿童少年身体发育
  • 男女第二性征顺序分开背女孩通常乳房先发育，再到阴毛、腋毛；男孩通常阴毛、腋毛、胡须。两组顺序不要混成一条线。相关章节：儿童少年心理行为发育
  • 初潮和遗精是标志，不是终点月经初潮说明女性性发育进入重要阶段，但排卵和周期还可能不稳定；遗精是男性生殖功能开始成熟的重要标志。题目说“初潮等于性成熟完成”，一般就是错的。相关章节：儿童少年心理卫生问题
  • 成熟裂隙：身体先到了，角色还没到生理上已经接近成人，心理社会角色和应对能力却没准备好。很多青春期冲突不是简单一句“叛逆”，而是这两边没同步。相关章节：儿童少年心理卫生问题、儿童少年伤害与暴力

前后章联系：第二章讲身体发育，这一章把镜头推到青春期；第三章的心理变化在这里和生理变化撞在一起。

考试怎么问：最爱考 puberty 和 puberty timing、PHV 与 PHA、男女第二性征顺序，以及“初潮是否等于性成熟完成”。

这只是复习时用的抓手。真碰到争议题，还是回章节原文和课件。

这章怎么看

青春期这章最容易混的不是年龄，而是三个词：adolescence、puberty、puberty timing。先把它们分开，再去看生长突增、第二性征和性心理。

一、三个概念

青春期 adolescence：个体从童年向成年过渡的时期，通常为 10～19 岁。课件给出女性约 10～18 岁、男性约 12～19 岁的跨度，男女起止年龄的写法在不同资料中略有差异。

青春发动期 puberty：青春期早期生殖系统发育与成熟的生物学变化过程，平均约 4.5 年。

青春发动时相 puberty timing：生长突增、乳房发育、阴毛发育、月经初潮等事件出现的时间模式。

青春期一般分为早期、中期和后期：

  • 早期：以生长突增为主，性发育开始
  • 中期：性器官和第二性征迅速发育，出现月经初潮或首次遗精
  • 后期：生长速度减慢至骨骺融合，性发育接近成人，社会心理发展加速

二、内分泌变化

青春期启动主要涉及下丘脑-垂体-性腺轴（HPG 轴）。两个重要现象是：

  • 性腺功能初现 gonadarche
  • 肾上腺皮质功能初现 adrenarche

课件提到的两种启动假说是：中枢神经抑制机制减弱，以及 HPG 轴对性激素负反馈敏感性下降。

三、生长突增

常用指标：

  • 身高速度高峰 PHV
  • 身高速度高峰年龄 PHA
  • 体重速度高峰 PWV
  • 体重速度高峰年龄 PWA

生长突增的顺序大致为：足长 → 下肢长 → 手长 → 上肢长。由于下肢先增长，青春前期坐高指数下降，出现“长腿”体态；青春中后期躯干增长加快，坐高指数回升。

成熟类型：

  • 早熟型：体重/身高比值较高，盆宽肩窄，相对矮胖
  • 晚熟型：体重/身高比值较低，盆窄肩宽，相对瘦高
  • 一般型：介于两者之间

四、性发育

男性：

  • 第二性征顺序：阴毛 → 腋毛 → 胡须
  • 遗精是男性生殖功能开始成熟的重要标志

女性：

  • 乳房发育通常是第一个信号
  • 第二性征顺序：乳房 → 阴毛 → 腋毛
  • 月经初潮是女性性发育的重要里程碑

五、性心理与成熟裂隙

青春期性心理常经历异性疏远期、异性爱慕期和两性初恋期。

成熟裂隙 maturity gap：生理成熟与心理社会成熟不同步，青少年可能已经具备成人样的身体，但社会角色和应对能力尚未准备好，容易出现适应困难。

往年题反复考的地方

公众号资料按“定义—内分泌—体格—性发育—性心理”整理。反复出现的是青春期和青春发动期的区别、puberty timing、PHV/PHA/PWV、生长突增顺序、男女第二性征顺序、初潮和遗精的意义，以及成熟裂隙。2024 年考试回忆里有 puberty 和 puberty timing 的英文简答。

对应本章题库：做本章题。其中已收录 2024 年 puberty/puberty timing 英文题。

容易做错的地方

  • 青春期是年龄/社会角色概念，青春发动期强调生殖系统成熟的生物学过程。
  • 女孩乳房发育通常早于阴毛和腋毛，男孩阴毛通常早于腋毛和胡须。
  • PHV 是速度峰值，PHA 是出现速度峰值的年龄。
