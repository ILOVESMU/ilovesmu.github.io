第五章 生长发育影响因素

遗传、环境、社会因素和行为方式怎样影响生长发育。

顺序学习纯刷题文字游戏
这一章怎么记记不住时点开

遗传给一个范围，环境决定最后走到哪。别把“遗传度高”理解成“改不了”。

  • 遗传决定潜能，环境决定实现程度遗传影响可能达到的范围，营养、疾病、家庭和学校条件影响最后实现多少。遗传度高只说明群体差异里遗传贡献大，不等于个体完全被基因锁死。相关章节：生长发育调查与评价
  • 双生子研究为什么能估遗传度同卵双生子基因相似度接近 100%，异卵约 50%。比较两组性状相似程度，就能估计遗传贡献。GWAS 估出来的遗传度常更低，这个差距叫“遗传度缺失”。相关章节：生长发育调查与评价
  • 表观遗传改的是表达，不是 DNA 字母DNA 序列没变，甲基化、组蛋白修饰这些东西会改变基因开不开、开多大。它可以受环境影响，也可能传给下一代，但不是基因突变。相关章节：健康问题、健康状况与健康促进策略
  • 春天长个，秋天长肉这是课件给的季节规律，方向别记反。春天身高增长较快，秋天体重增长较快。相关章节：儿童少年身体发育
  • 儿童为什么更容易受空气污染影响气道比较窄，呼吸频率又高，同样浓度的污染，吸进去的相对更多。铅主要伤神经和造血系统，看到儿童铅暴露，先想到这两块。相关章节：儿童少年常见病

前后章联系：第一章讲规律，这一章讲谁在推着规律走；第六章接着讲怎么把这些影响测出来。

考试怎么问：“遗传决定现实性”是说反了；表观遗传不是基因突变；春季身高、秋季体重的方向也常被改掉。

这章怎么看

这章不用背一长串影响因素。先抓住一句：遗传给范围，环境决定最后走到哪。剩下的遗传度、双生子、表观遗传、季节和污染，都是在这句话周围展开。

一、遗传因素

遗传是形态结构、生理功能和身心发育等性状在亲代与子代之间的相似性和连续性。基因决定潜能，环境决定潜能实现的程度。

遗传度

遗传度（heritability）估计某性状在群体中有多大比例的变异由遗传因素决定。

常用研究方法：

  • 双生子研究：同卵双生子基因相似度接近 100%，异卵约 50%
  • 全基因组关联研究 GWAS
  • 家系研究

GWAS 估计的遗传度常低于双生子研究，称为“遗传度缺失”，可能与微效基因遗漏、表观遗传和基因-环境互作有关。

表观遗传

表观遗传不改变 DNA 序列而调控基因表达，常见形式包括 DNA 甲基化和组蛋白修饰。它具有可遗传性和可逆性，不遵循孟德尔遗传定律。

基因与环境

  • 基因-环境相关：个体的环境可能与遗传倾向相关
  • 基因-环境交互：不同遗传背景下，同样环境的影响不同

二、物质环境

  • 地理气候：日照、气温年较差等与体格发育有关
  • 季节：春季身高增长较快，秋季体重增长较快
  • 空气污染：儿童气道狭窄、呼吸频率高，更易受影响
  • 铅污染：铅是毒性较大的重金属，影响神经和造血系统
  • 环境内分泌干扰物：干扰激素产生、释放、运输、代谢和作用
  • 噪声、电磁辐射和放射性污染

三、社会决定因素

社会经济状况、医疗卫生保障、家庭生活质量、文化和教育、现代媒体和娱乐方式都会影响生长发育。家庭因素包括家庭经济状况、父母受教育程度、亲子关系和家庭结构。

四、行为生活方式

膳食与营养、体育锻炼、睡眠、视屏和网络使用是重点。长期网络使用可能带来睡眠不足、久坐、视屏时间过长和心理行为问题。

往年题反复考的地方

公众号笔记反复写“遗传决定潜能，环境决定实现程度”。常考遗传度、双生子研究、GWAS 与遗传度缺失、表观遗传、基因-环境相关和交互、季节变化、铅污染、家庭环境和生活方式。爱课还考过家庭环境包括什么、长期上网有没有害、遗传和环境谁决定现实性。

对应本章题库：做本章题。

容易做错的地方

  • 遗传决定“可能性/潜能”，环境决定“现实性/实现程度”，不要把两者说反。
  • 遗传度高不等于不可改变，环境仍可影响潜能实现。
  • 表观遗传不是 DNA 序列突变。
