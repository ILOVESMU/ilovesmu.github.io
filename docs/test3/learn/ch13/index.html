第十三章 学校健康教育与健康促进

健康教育、健康促进、教学方法、理论和评价。

顺序学习纯刷题
这一章怎么记记不住时点开

健康教育主要教人怎么做，健康促进还要让环境、政策和制度支持这么做。

  • 一个劝你走，一个把路铺好健康教育主要通过信息传播和行为干预；健康促进还要动政策、环境、社区和卫生服务，让健康选择更容易实现。范围一个窄，一个宽。相关章节：学校教学设施与设备卫生
  • 课堂讲授最普遍，但不算参与式课堂讲授适合大班系统传授知识，是国内学校最常用的方法。参与式要学生开口、动手，比如同伴教育、角色扮演、小组讨论、案例分析和头脑风暴。讲座偏单向，也不在参与式名单里。相关章节：教育过程卫生
  • 大众媒体是间接方法隔着屏幕传播，不需要面对面，所以属于间接健康教育方法。同伴教育、课堂、讲座、头脑风暴都要人到场。相关章节：学校教学设施与设备卫生
  • 组织改变：解冻、改变、再冻结先让学校觉得非改不可，再上课、做同伴支持、建戒烟小组和无烟环境，最后把制度、巡查、奖励和评价固定下来。只劝个人，不算组织改变。相关章节：健康问题、健康状况与健康促进策略
  • 评价分过程、影响、结局过程评价看活动有没有按计划做，影响评价看知识、态度和行为有没有变，结局评价看健康结果。RE-AIM 再补覆盖、有效、采纳、实施和维持。相关章节：生长发育调查与评价

前后章联系：第十二章讲学校环境，这一章讲怎么让人和行为一起改变；到这里，课程从“看见问题”走到“设计干预”。

考试怎么问：戒烟题连续几年出现，答题要写组织和制度，不是只劝个人；讲座不是参与式；大众媒体不是面对面方法。

这只是复习时用的抓手。真碰到争议题，还是回章节原文和课件。

这章怎么看

健康教育和健康促进不是一回事。前者主要教人怎么做，后者还要动政策、环境和制度。把这层区别抓住，后面的方法、理论和评价才不容易乱。

一、概念

健康教育：通过有计划、有组织、有系统的健康信息传播和行为干预，促使个人或群体掌握健康知识、树立健康观念，自觉采纳有益健康的行为和生活方式。

健康促进：不仅包括健康教育，还包括政策、环境、社区行动和卫生服务等综合策略，使健康选择更容易实现。

健康素养：个体获取、理解、评价和应用健康信息，作出健康决策的能力。

二、基本内容

  • 健康行为与生活方式
  • 疾病预防
  • 安全应急与避险
  • 生长发育与青春期保健
  • 心理健康

三、教学方法

课堂讲授是国内学校最普遍采用的方法，适合系统传授知识。参与式方法包括同伴教育、角色扮演、小组讨论、案例分析和头脑风暴。大众媒体属于间接健康教育方法。

四、主要理论与模式

  • 健康信念模式
  • 阶段变化理论
  • 组织改变理论：解冻、改变、再冻结
  • PRECEDE-PROCEED 模式
  • 社会认知理论

组织改变理论常用于设计戒烟干预：先让学校/组织认识到问题并产生改变动力，再实施课程、环境和支持措施，最后把新行为制度化。

五、评价

评价类型包括过程评价、影响评价和结局评价。常用 RE-AIM 框架关注覆盖范围、有效性、采纳、实施和维持。

往年题反复考的地方

公众号考试回忆里，用组织改变理论安排戒烟干预在 2022、2023、2024 年连续出现，是这一章最该拿的分。除此之外还要会健康教育、健康促进、健康素养的区别，五项基本内容，课堂讲授与参与式及间接方法，以及过程—影响—结局评价。答题时按解冻、改变、再冻结写，最后补制度化和评价指标。

对应本章题库：做本章题。其中已收录 2022/2023/2024 年戒烟干预往年题。

容易做错的地方

  • 讲座属于偏单向传播，不是参与式方法。
  • 大众媒体是间接健康教育方法，不是面对面参与式方法。
  • 健康教育强调信息传播和行为干预，健康促进的范围更广。
