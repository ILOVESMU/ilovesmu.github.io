# 维修

宿舍报修、电费充值、洗澡热水都可以在“南方医科大学总务处”公众号办理。高层和数字栋的报修流程基本一样。

电费在公众号的“电费充值”里绑定房间号后充值，大约只剩 8 度电时会收到提示。洗澡热水和宿舍用电也都在同一个入口附近。

如果遇到外校人员进入宿舍，及时打保卫处电话：**61648154**。
