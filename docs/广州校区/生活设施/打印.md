# 打印

## 图书馆一楼

图书馆一楼有四台打印/复印机，只能打印或复印黑白文件。

1. 到打印机旁边的电脑，把文件传上去（可以用微信文件传输助手，也可以用 U 盘）；
2. 按常规步骤设置打印参数，点击打印，输入自己的校园网账号和密码；
3. 在手机上打开“南方医科大学一卡通”小程序，确认余额，没有余额先充值；
4. 点击付款，会出现二维码；
5. 到打印机屏幕上选择打印/复印，扫描二维码，核对文件；
6. 需要打印的文件出现时再扫一次，建议先刷新手机上的二维码；
7. 打印机没有纸时，及时找旁边志愿者反馈。

## 高层一楼

高层一楼也有打印机，是顺德那套飞登云印。到本部后需要先把地点切换到本部，否则会打印失败、需要退款。这两台打印机有时会坏，赶时间的话优先去图书馆。
