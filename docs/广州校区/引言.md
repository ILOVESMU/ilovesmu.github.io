# 广州校区

广州校区（本部）位于广州市白云区京溪街道。和顺德校区相比，这里的楼层关系、宿舍类型和日常动线更集中，第一次来容易在“高层、数字栋、教学馆、图书馆”之间绕晕。

这篇把 2026 年两篇本部攻略按主题重新整理，分成地图、宿舍、快递、吃饭、运动、学习、就医、出行和宿舍搬迁几个部分。具体安排可能随学校通知变化，请以最新通知为准。
