第五章 生长发育影响因素

遗传给上限，环境给落点：遗传、物质环境、社会决定因素、行为生活方式怎样共同决定一个孩子长成什么样。

顺序学习纯刷题文字游戏
这一章怎么记记不住时点开

遗传给一个范围，环境决定最后走到哪。别把“遗传度高”理解成“改不了”。

  • 遗传决定潜能，环境决定实现程度遗传影响可能达到的范围，营养、疾病、家庭和学校条件影响最后实现多少。遗传度高只说明群体差异里遗传贡献大，不等于个体完全被基因锁死。相关章节：生长发育调查与评价
  • 双生子研究为什么能估遗传度同卵双生子基因相似度接近 100%，异卵约 50%。比较两组性状相似程度，就能估计遗传贡献。GWAS 估出来的遗传度常更低，这个差距叫“遗传度缺失”。相关章节：生长发育调查与评价
  • 表观遗传改的是表达，不是 DNA 字母DNA 序列没变，甲基化、组蛋白修饰这些东西会改变基因开不开、开多大。它可以受环境影响，也可能传给下一代，但不是基因突变。相关章节：儿童少年健康问题、健康状况和健康促进策略
  • 春天长个，秋天长肉这是课件给的季节规律，方向别记反。春天身高增长较快，秋天体重增长较快。相关章节：儿童少年身体发育
  • 儿童为什么更容易受空气污染影响气道比较窄，呼吸频率又高，同样浓度的污染，吸进去的相对更多。铅主要伤神经和造血系统，看到儿童铅暴露，先想到这两块。相关章节：儿童少年常见病

前后章联系：第一章讲规律，这一章讲谁在推着规律走；第六章接着讲怎么把这些影响测出来。

考试怎么问：“遗传决定现实性”是说反了；表观遗传不是基因突变；春季身高、秋季体重的方向也常被改掉。

这只是复习时用的抓手。真碰到争议题，还是回章节原文和课件。

这章的骨架

p3 先问：影响生长发育的因素有哪些，研究它们是为了什么。p4 的结构图给答案：左边内因（遗传）→潜能、可能性、不可控；右边外因（环境）→速度及可能达到的程度、现实性、可控；两条都指向“生长发育个体差异”。

研究目的（p4 原话）：充分利用有利因素，尽可能消除或控制不利因素，最大限度发挥遗传潜能。注意是发挥，不是突破——基因型改不了，能改的落在营养、疾病、睡眠这些可控项上，目标是别让孩子因为可控项停在潜力线以下。

一、遗传因素

遗传传的是什么

定义（p5）：遗传指形态结构、生理功能及身心发育等性状在亲代与子代之间的相似性和连续性。相似性说“像”，连续性说“代代都像”，只记前者会漏掉代际传递。机制是父母双方基因组合经受精卵传给后代，再通过基因表达决定表型。

紧接一句最常考（p5）：基因决定生长发育的潜能，潜能能否充分发挥受环境和社会决定因素制约，也受环境-遗传交互作用影响。凡把“遗传决定”读成“注定”的选项，都能判错。

遗传度：最容易被误读的指标

定义（p6）：估计某一性状在群体中有多大比例的变异是遗传因素决定的。三个词要咬住——群体、变异、比例。所以“我的身高 80% 来自遗传”在方法上说不通：遗传度谈的是群体里差异的归因，不拆到个人。

那把 0 到 1 的刻度尺：越靠近 1 遗传作用越大，越靠近 0 环境作用越大。高遗传度不等于不可改变——近视双生子遗传度约 80%（p8），可近视率几十年间快速上升，基因库不可能这样变。

三种估计方法

p6 列三条路：家系研究、双生子研究、GWAS。

双生子（p7）：同卵基因 100% 相同，异卵 50%。同卵一致性明显高于异卵→遗传主导；两者相近→环境主导。前提是“双生子的环境差异大小一致”，现实中常打折扣，所以可能高估遗传作用——同卵常被更相似地对待。

GWAS（p8）：全基因组范围内找与性状相关的变异，用这些变异能解释的方差估遗传度，不依赖亲属关系。近视：GWAS 约 18.4%，双生子约 80%。同一性状差四倍多，叫遗传度缺失（missing heritability），指 GWAS 估计值低于双生子估计值的现象。四条原因：双生子估计偏高、微效基因遗漏、表观遗传贡献、基因-环境互作。

遗传度随性状和年龄变

p9 按功能域分三档：眼、耳鼻喉、皮肤和骨骼接近或高于 0.6；认知 0.4～0.5；生殖低于 0.3。

同页表 6-1（中国双生子队列，Liu Q 等 2015）把三个指标各拆成加性遗传 / 共同环境 / 特殊环境：

年龄（岁） BMI 身高 体重
0～2 0.13 / 0.77 / 0.10 0.12 / 0.83 / 0.05 0.26 / 0.65 / 0.10
15～17 0.54 / 0.35 / 0.11 0.87 / 0.11 / 0.03 0.66 / 0.27 / 0.07

结论（p9 原话）：体重、身高和体质的遗传度随年龄增长逐渐增高。读法：0～2 岁 BMI 共同环境 0.77，说明婴幼儿胖不胖主要看家里怎么喂；到 15～17 岁加性遗传升到 0.54。身高那列起步就高，青春期 0.87。

两个术语课件没解释（补充）：共同环境是家庭成员共享的部分，收入、住房、喂养方式；特殊环境是个人独有的部分，同伴、偶然疾病。

家族聚集性与种族

家族聚集性（p10）：某些性状或疾病在家族中出现的频率高于一般人群。图上并列两条路径——“父母双方遗传因素”和“家庭成员间相似的环境因素”。这个并列就是考点：家族聚集不等于遗传，一家人共享的不只基因，还有饭桌和养育方式。

种族：具有共同起源和共同遗传特征的人群。种族差异尤其体现在体型、躯干和四肢长度的比例上（p10）——是比例，不只是高矮。

单基因、多基因

p11：单基因性状仅由一对等位基因控制，多遵循孟德尔规律，决定质量性状，群体中呈不连续分布；多基因由多个基因共同控制，每对效应微小，除累加还受环境影响，数量性状呈连续分布，近似正态。

成对记：单基因—质量性状—不连续；多基因—数量性状—连续。

p12 用身高串起来：身高是多基因数量性状，群体分布连续（图上横轴身高、纵轴占比，男女两条分布分开画）。同页留例外：FGFR3 基因突变导致软骨发育不全，患者平均身高仅 130 cm，即侏儒症——单基因突变能把人直接推到曲线最左端。

表观遗传：不改字母，改读法

定义（p13）：不改变基因的 DNA 序列而调控基因表达的可遗传或可继承机制的统称。三个特点：序列不变而表型改变；可遗传也可逆；不遵循孟德尔定律。

五种方式：DNA 甲基化（最常见）、组蛋白修饰、非编码 RNA 调控、基因印迹、染色质重塑。

p14 的链条要能默写：母亲孕期服用己烯雌酚 → 子代 HOXA10 基因甲基化异常 → 生殖道的发育编程改变 → 子代永久性生殖道异常、阴道癌发病风险增加。

“可逆”是重点：表观修饰能被环境再改写，这正是干预窗口。别把它等同基因突变——突变是字母改了，表观是字母没改、但某些段落被标成“不读”。

基因和环境怎么“一起”起作用

两种“一起”，中文只差一个字。

rGE，基因-环境相关性（p15）：基因与环境共同作用和串联变化，个体的生活环境很可能是遗传自选择的结果，即遗传影响个体对环境的选择。三型：

  • 被动型：父母传基因，也给家庭环境。爱读书的父母既传“阅读基因”，也给了满屋书和共读时间。
  • 主动型：个体主动选择或创造与自身遗传倾向相关的环境。有运动天赋的孩子更愿意去球场。
  • 唤起型：遗传特征引起他人反应。安静的孩子容易被老师多照顾，好动的常被提醒。

G×E，基因-环境交互作用（p16）：不同遗传倾向下，相似的环境经历对个体的影响效应不同；不同环境经历下，遗传对个体的影响效应也不同。

分开记：rGE 讲“环境从哪来”，G×E 讲“环境的效果被基因型改”。

  • (a) 素质—应激模型：G_L 高位平坦，G_H 从低处陡升，在正向端汇合。高风险型只在恶劣环境里吃亏，环境一好差距消失。
  • (b) 生物生态模型：G_L 随环境陡升，G_H 基本平坦。某一基因型对正向环境特别敏感，吃得到好环境的红利。
  • (c) 差异易感性模型：两条线交叉。高易感型环境差时更糟、环境好时更好。
  • (d) 加性效应（无交互作用）：两条平行线。基因、环境各有主效应，但环境效果不因基因型而变，只是相加。

p17 把 G×E 落到肥胖：携带 FTO 风险基因型的儿童，脂肪高峰提前、脂肪重积聚提前、BMI 速率增加，肥胖风险增加；而 5 个月以上的纯母乳喂养可降低 FTO 高风险基因型儿童的肥胖风险。遗传给倾向，环境改斜率。

二、物质环境

物质环境是人类赖以生存的物质基础（p18）。这一节从大到小：地理气候，再到污染。

地理气候：有影响，但别全算在它头上

p18 的指标：日照时长、年均气温、气温年均差、平均地表温度、年降水量、平均相对湿度、海拔高度、大气压、平均水气压。

p19 用 2019 年全国学生体质与健康调研：汉族聚居省区市省会所在地、以秦岭淮河为界，北方 15 个群体、南方 15 个群体。举几行（单位 cm）：6 岁男生 122.7 与 120.9，差 1.8；15 岁男生 172.5 与 170.1，差 2.4；15 岁女生 161.4 与 159.1，差 2.3；18 岁男生 174.3 与 171.5，差 2.8。

读表的关键：每列都带 n 和标准差（如 122.7±5.3），标准差 5～9 cm，是那 2 cm 的好几倍——群体均值有差异，个体差异更大。

同页定性：地域差异尤其是长期趋势，不全是地理气候作用的结果，还与各群体的发展起源、生活方式、饮食习惯及社会经济状况密切相关。答题分层：气候日照（影响户外活动、维生素 D 合成）是一层，遗传背景一层，经济与膳食结构一层。全归气候、全归基因，都是偷懒。

季节：春天蹿个，秋天长肉

p20：春季身高增长最快，3～5 月的身高增长值为 9～11 月的 2 倍左右，新骨化中心出现较多；秋季相反，体重增长最快在 9～11 月，全年体重总增长的 2/3 发生在 9 月至次年 2 月，炎热夏季有些儿童体重增长很少；中国女童初潮多发生在 2～3 月和 7～8 月。

记法：春天长个，秋天长肉，初潮有自己的季节。

化学性污染

定义（p21）：由于自然灾害、工业生产、人类活动等使地区环境的化学组成发生变化，使对人体有害的化学物质成分增加的过程。课件用三个“最”定位：最常见、危害最直接、最严重；并强调儿童少年易感性高于成人。

空气污染（p22）：室外来自工业排放、汽车尾气，主要是颗粒物、二氧化氮、二氧化碳、臭氧；室内来自燃料燃烧、建筑材料和家具，主要是环境烟草暴露、甲醛、挥发性有机物。影响两层——长期广泛影响健康，特别是肺功能和神经系统发育；孕期母体暴露显著增加胎儿宫内生长受限和早产风险。

铅（p23）：环境污染物中毒性最大的重金属之一，环境铅暴露仍是影响儿童青少年健康的主要化学性污染物。表 6-2-1 按血铅（微克/分升）分档：

血铅水平 儿童健康影响
＜5 神经系统：智力下降、学业成绩下降；注意力相关行为和问题发生率增加
＜10 神经系统：听力下降。生殖和发育：减少出生后生长、女孩和男孩的青春期延迟
10-39 神经系统：神经传导减慢。血液：血红蛋白降低、贫血
40-79 胃肠道：腹痛、便秘、绞痛、厌食、呕吐
≥80 神经系统：严重的神经影响、抽搐、昏迷、瘫痪和死亡

低剂量段害的是智力和学业，不是中毒症状——孩子看着没病，成绩和注意力在往下掉。系统受累有先后：神经最先最敏感，然后造血，再往后胃肠道和严重神经事件。

同页结论要单独记：任何铅暴露都可能对儿童健康产生不良影响，因此不存在“安全”的血铅水平，理想情况下血铅应为零。与分档不矛盾——分档说不同水平下的典型表现，公共卫生说没有阈值。

EEDs，环境内分泌干扰物（p24），定义三层：干扰机体内天然激素的产生、释放、运输、代谢、消除、结合和功能；破坏机体内环境稳定；对个体功能和发育造成影响。清单：邻苯二甲酸酯、双酚 A、二恶英、有机氯农药、己烯雌酚、高氯酸盐、铅、镉、多氯联苯类。三后果：性早熟、抑制免疫系统正常功能、神经发育毒性。特点是不直接杀细胞而干扰激素信号，所以低剂量、长期暴露就可能有影响，窗口落在发育关键期。

物理性污染

p25 三类。噪声靶器官最明确：损害听觉最直接，同时影响视觉功能、神经心理行为发育，长期还引起心血管、消化、内分泌系统功能紊乱。电磁辐射分电离与非电离，低强度慢性射频的三条影响是神经系统发育、神经衰弱、视力。放射性污染口径克制：微量暴露一般不影响健康，需达到一定剂量才发生有害作用——讲的是剂量—效应关系，不能读成“放射性无害”。

有一处缺口要留意：p21 的标题写的是“化学性、物理性、生物性”三类，但课件只展开了前两类，生物性污染（病原微生物、寄生虫、过敏原等）没有单独页面。考到“分几类”按标题答三类，具体内容课件没给。

三、社会决定因素

社会环境指人类生存及活动范围内的社会物质和精神条件的总和（p26），与自然环境相对。整节判断：多层次、多方面的综合效应，不仅体格，对心理、智力和行为发育也有深远影响。

SES，社会经济状况（p27）是社会因素中应用最广泛的概念，可独立于自然环境因素直接影响生长发育。同页有个阶段判断：社会经济发展到一定阶段后，基础物质生活（食物可及性与丰富性、卫生保健）的影响逐渐削弱，社会文化相关指标（父母职业、受教育程度、家庭养育环境）的重要性逐渐凸显。

医疗卫生保障（p28）：政府通过财政或政策支持，为保证居民获得最基本的公共卫生和医疗服务而提供的制度安排。三条关系：经济发展水平决定政府对医疗卫生的投入；卫生资源配置及服务可及性、公平性与疾病流行、人群健康密切相关；儿童健康常作为衡量国家或地区经济、文化和医疗卫生发展水平的重要指标。

家庭环境六项（p29），旁边标着“反映家庭生活质量的因素”：

  • 家庭经济状况：直接影响居住环境、膳食营养水平、社交活动和智力投资
  • 父母受教育程度：家庭社会经济状况中的重要正向因素，母亲的教育程度对儿童影响尤为显著
  • 家庭结构：显著影响体格与行为发育，我国核心家庭和大家庭约占 3/4
  • 家庭氛围：温馨氛围对健全人格有正向作用；紧张氛围（父母经常争吵甚至家庭暴力）阻碍心理健康，孩子易情绪多变、社交退缩、出现问题行为
  • 亲子关系：儿童最早建立的人际关系
  • 教养方式：影响情绪发展、人格形成、学业成绩、社会适应性

两个细节常考：母亲受教育程度影响尤为显著；核心家庭和大家庭约占 3/4。同页还有前提：良好家庭环境对小年龄儿童的作用更为显著。

文化和教育三层（p30）：家庭教育是人生教育的基础和起点；学校教育影响健康和社会适应能力；社会教育是家庭学校之外的一切影响因素，是重要补充。三者并非独立，与政治制度、经济状况、社会福利、法律法规相互渗透。

四、行为生活方式

生活方式（p31）：人们在一定社会文化、经济、风俗、家庭等因素影响下形成的一系列日常生活习惯和生活模式；行为是生活方式与社会背景动态关系的体现，包括膳食、运动、睡眠、娱乐、消费、社会交往。

膳食模式（p32）：膳食中不同食物的数量、比例、种类或组合，以及习惯性消费频率；不只反映饮食习惯和生活水平，也反映民族传统文化、经济发展和地区环境资源。

p33 是《中国学龄儿童膳食指南（2022）》的宝塔，分 6～10、11～13、14～17 岁三档，量随年龄递增。14～17 岁：谷类 250～300 g/天（全谷物和杂豆 50～100）、薯类 50～100；蔬菜 450～500、水果 300～350；畜禽肉 50～75、水产品 50～75、蛋类 50；奶及奶制品 300、大豆 105～175 g/周、坚果 50～70 g/周；油 25～30、盐 ＜5 g/天；水 1200～1400 ml。

三档对照，记三列就够（依次为 6～10、11～13、14～17 岁）：谷类 150～200 / 225～250 / 250～300，蔬菜 300 / 400～450 / 450～500，水果 150～200 / 200～300 / 300～350，单位都是 g/天。盐在 6～10 岁是**＜4 g/天**，11 岁起才 ＜5 g/天；奶及奶制品三档都是 300 g/天。

读宝塔三点：蔬菜量高于水果；奶按“每天”计，大豆坚果按“每周”计；油盐在塔尖是限量，不是必需吃够。

饮食行为（p34）：指南特别指出学龄儿童应吃好早餐、合理选择零食、培养健康饮食行为。三餐能量比 3∶4∶3。不吃早餐或早餐营养不足，会降低上午学习效率、影响学习认知能力，还导致体能降低、影响体格发育。其余是行为层面：不偏食挑食、不暴饮暴食、避免盲目节食、合理选零食、减少在外就餐频率。

体育锻炼（p35）定义：运用各种体育手段，结合日光、空气、水等自然力和卫生措施，以发展身体、增进健康、增强体质、娱乐身心为目的的身体活动过程，是儿童少年主要体力活动的形式。

作用两组：

  • 身体发育：代谢及能量消耗显著增加、改善消化吸收；促进肌肉骨骼生长，关节韧带更坚韧灵活，促进 VD 合成；心功能储备提高；呼吸功能增强、降低呼吸道感染风险；其他——内分泌、学习效率
  • 心理行为发育：全面提高心理素质、促进个性发展；调节情绪、有助于情绪稳定；显著增强自尊心和自信心

“学习效率”课件列在身体发育—其他里，不是心理行为，别按常识想当然。

同页留了个问题（课件未答，补充）：体育锻炼对身高体重有影响吗？稳妥说法——通过促进骨骼生长、改善代谢与内分泌支持体格发育，有利于实现生长潜力，但不宜说成“多运动能突破遗传身高”。

睡眠（p36）被叫作“脑的营养剂”。作用：消除疲劳、机体复原、维持和巩固记忆；维持人体代谢和免疫平衡；促进体格和神经行为发育，尤其对生长发育期儿童青少年。补充：生长激素分泌高峰在深睡眠，睡眠不足会压缩这个窗口。

三条建议：保障充足睡眠时间；定时就寝、定时晨起的规律作息；从制度上保障早晨上课时间因地制宜，不同地理经度地区可灵活决定不同季节（尤其冬春季）的早晨上学时间。

电视（p37）内容双面：科普、历史、地理节目提升知识面、理解力、智力和创造力；暴力犯罪内容对心理健康不良，可能引发暴力、酗酒、吸毒等危险行为。视屏时间过长四条：挤占与家人互动，不利语言、情绪和认知发展；挤占体力活动，不利肌肉骨骼和大脑发育；限制思维范围，影响个性与社会适应；久坐导致近视、肥胖增多。

网络（p38）：正面是信息与学习平台、拓宽思维视野。负面集中在网络成瘾：挤占睡眠和运动、身体素质下降；眼干、视物模糊、视力下降甚至角膜视网膜损害；个性迷失、交流能力弱化；不适宜信息诱发易怒、冲动、攻击等危险行为。陷阱题“长期使用网络不会对儿童少年健康造成危害”，错在把使用与成瘾混为一谈。

玩具和读物（p39）：玩具是“简单知识的物质载体”，训练感知觉、注意力、手眼协调、肌肉运动，促进认知发育；读物是“信息和知识的物化载体”，促进智力、语言、情感、社会性发展。

六、最容易混淆的概念

容易混的两组 关键区别 判断要点
遗传度 vs 遗传 群体变异的归因比例 / 性状的代际传递 遗传度不能拆到个人头上
遗传决定潜能 vs 环境决定现实性 一个给上限，一个给落点 方向反了就是错项
单基因 vs 多基因 一对等位基因、质量性状不连续 / 多对微效基因、数量性状连续 能连续测量、近似正态的多半是多基因
表观遗传 vs 基因突变 序列没变、表达被改 / 序列本身变了 甲基化不是突变，而且可逆
rGE vs G×E 环境与基因同源或被挑选 / 环境效应被基因型修饰 相关讲“从哪来”，交互讲“效果变不变”
共同环境 vs 特殊环境 家庭成员共享 / 个体独有 家里共有的算共同，各自遇到的算特殊
遗传度缺失 vs 遗传度低 方法差异造成的低估 / 该性状遗传贡献小 两个方法估同一性状差很多，才叫缺失
家族聚集性 vs 遗传 家族中频率高 / 基因代际传递 家族共享环境也会造成聚集
室外 vs 室内空气污染 工业排放、汽车尾气 / 燃料燃烧、建材家具 看来源，不看浓度
血铅分档 vs 安全阈值 分档描述典型表现 / 公共卫生认为无安全值 任何水平都有风险，理想为零
