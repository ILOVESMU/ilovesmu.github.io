# 超市

- **快递服务中心旁**：有京东便利店，取快递时可以顺手买东西。
- **学一至学四**：基本都有便利店，学四主要是自助贩卖机，货物比其他三层少；学一的可口可乐相对便宜。
- **教职工活动中心**：从南方医院菜鸟驿站右边的通道上坡，进入教职工活动中心后可以看到超市，旁边还有南方快印和南方医院健身房。

日常买日用品、饮料和零食，优先看宿舍附近的便利店；需要更全的选择，可以去校外超市或太阳城。
