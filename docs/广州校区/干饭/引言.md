# 干饭

## 学一至学四

高层旁边的饭堂按楼层分为学一、学二、学三、学四，共四层：地下一层是学一，地上三层依次往上。整体口味不错，选择也多，丰俭由人。

最下面要下楼梯的是学一。学一门口有外卖柜，外卖地址填“南方医科大学第一食堂”就会送到这里。学一有面包店和自动售卖机，旁边是服务台；楼梯旁还有一个食品安全检测中心。

学一至学四基本都有便利店，学四主要是自助贩卖机，东西比其他三层少。学一的可口可乐比较便宜；学三、学四靠近楼梯有小桌子，可以反馈问题。学四有家兰州牛肉面，具体店铺每学期会换，寒暑假学一、学二还可能装修，菜单以现场为准。

各层风格不太一样：学三自选菜常放辣椒，小炒偏香辣；学四的小炒如果选鸡蛋，会做成荷包蛋或溏心蛋。餐具一般在各处的消毒箱里取，有些店会另外提供一次性筷子；回收地点会随装修变化，跟着人流走通常就能找到。

部分店家可以送外卖到宿舍，店面窗户或桌上会贴小程序二维码，外卖软件里也能点。高层的地址写“高层+房间号”，一般能送到临近楼层的电梯间；数字栋只能放在一楼，例外不多。不过送餐的是本校学生兼职，时间不固定，有时要等一个多小时，也可能不拍照，谨慎选择。

## 营业时间与假期

每家店营业时间不同，食堂大楼梯转角一般会贴具体时间。学一、学二通常开得久一点，学一晚上甚至可以用来自习。

寒暑假大部分门店不营业，一般只有学四学校自营的自选饭堂开放。开学后店铺也可能调整，以现场为准。

## 外卖

外卖地址可以填“南方医科大学第一食堂”，送到学一门口的外卖柜。外卖有时会被拿走，查监控需要找辅导员签字盖章，可以先问辅导员流程；外卖柜旁边通常也贴着说明海报。

## 学五食堂

幼儿园附近还有一个学五食堂。一楼是小麒麟餐馆，和外面餐厅类似，上菜比较慢，价格也接近校外，特别饿的时候要谨慎；二楼和学四类似，但会稍贵一点，附近居民去吃得多。学五比较远，有兴趣可以试试。

小北门和太阳城周边的吃喝，放在[出行及游玩](../出行及游玩.md)里。
