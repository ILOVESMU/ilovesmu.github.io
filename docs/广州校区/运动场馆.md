# 运动场馆

## 操场

本部操场人比较多，运动时注意安全；最近在装门禁，希望能缓解人流。开放时间一般为 **6:00-23:00**。

## 体育馆与游泳馆

体育馆需要预约，场地基本都要收费，可以在“南医大体育场馆预约”小程序预约。

体育馆正下方、操场下面的停车场旁边还有游泳馆，也是男生体测做引体向上的地方。体测时可以直接从体育馆进去再下去；平时要往南门（司法鉴定中心）那条路右拐绕下去。

游泳馆会在夏季发布开馆通知，具体时间和票价看学校最新消息。

## 健身房

高层楼下负一楼有一个免费健身房，也需要预约，在“南方医科大学学生处”公众号的“管理服务-场地预约”里操作。

如果想换环境，可以去校外付费健身房，比如南方医院健身房，环境相对更好，价格大约 2200 元/年。
